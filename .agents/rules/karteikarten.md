# Karteikarten *(optional, nur falls beim Setup aktives Lernen gewählt wurde, sonst diese Datei löschen)*

> Teil der Vault-Schreibkonventionen (`.agents/rules/`, Übersicht in `AGENTS.md`). Nur laden, wenn Vault-Inhalte **angelegt oder editiert** werden.

- **Karten leben zentral in `Lernen/Karten.md`, nie in den Notizen.** Kein `## Quiz`-Abschnitt in Wissens-Notizen.
- **Aufnahmekriterium:** nur was die Person **aus dem Kopf können muss** (Daily, Review, Gespräch), nicht was sie nachschlagen kann. Das meiste Wissen ist Nachschlage-Wissen und wird **keine** Karte. Im Zweifel keine.
- **Form:** atomar (eine Karte = eine Sache), Anwendung statt Definition ("was tust du, wenn X?"), Antwort knapp, mit Link zur Herkunfts-Notiz.
- Karten entstehen bewusst über Brain-Input (Tor) und Brain-Bereinigen (Qualitätswächter), nie automatisch beim Anlegen einer Notiz.

## `type` bei Wissensnotizen bewusst setzen

"Muss ich das im Kopf haben?" → **Konzept**. "Nur nachschlagen?" → **Referenz**. "Ein Ablauf, den ich ausführe?" → **Vorgehen**. `type` steuert die Abfrage **nicht**, es markiert nur die Rolle; ob eine Karte entsteht, entscheidet allein das Aufnahmekriterium oben.
